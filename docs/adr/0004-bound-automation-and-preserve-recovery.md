# Bound automation and preserve recovery

Run workflow authorizes automatic progress only within explicit Run Scope and stops at native checkpoints, approval, failure, or attention states. Automated provider runs share an environment capacity of two by default, use isolated worktrees, and work the ticket frontier fairly. Only provably pre-accept dispatch failures retry; side-effectful interruption preserves threads, worktrees, and diffs for explicit recovery. Review permits at most four correction cycles, and merge conflicts receive one automatic repair run before escalation.
