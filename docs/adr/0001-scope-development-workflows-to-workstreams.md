# Scope Development Workflows to Workstreams

A Development Workflow belongs to a durable Workstream rather than a thread. The user explicitly attaches one Workstream to an existing Wayfinder thread; structured Wayfinder artifacts are backfilled and observed, while stage and ticket runs may use focused linked threads. This preserves context across provider sessions and clients, permits multiple Workstreams in one environment, and prevents duplicate observers on the same Wayfinder thread.
