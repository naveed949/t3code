# Split authority and require structured evidence

The tracker remains authoritative for published ticket content, status, parentage, and blocker edges; T3 owns Workflow Run scope, controls, linked threads, worktrees, and integration state. Workflow progress derives only from versioned structured artifacts, synchronized tracker state, persisted events, and typed receipts—not assistant prose. Missing capabilities or stale synchronization block dispatch instead of prompting T3 to emulate skills or invent truth.
