# Publish one reviewed Workstream pull request

After all in-scope tickets are integrated and validated, the Workflow Run reaches Locally Integrated. A separate approved Publication stage pushes the Workstream Baseline and creates one draft pull request carrying the Workflow PRD's closing relationship. Execution ends at Published for Review; merge remains external, closes the PRD through tracker behavior, and advances the passive projection to Merged. Deployment and post-publication fixes require separate authority.
