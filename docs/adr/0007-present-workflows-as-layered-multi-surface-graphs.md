# Present Workflows as layered multi-surface graphs

The existing thread-local Plan view remains separate from a Workstream-scoped Workflow view. Web and desktop use a stable layered Compound Workflow Graph plus a complete accessible outline; mobile uses the complete outline, inspector, checkpoints, and controls without a phone canvas in v1. The canvas is a bounded visual projection with explicit continuation summaries, while selecting nodes is side-effect-free and all mutation occurs through server-projected named actions.
